# Gold Karigor Tracker 
A production-level SaaS application built for
a real gold business to track karigor work items.

## Live Demo
Frontend: https://goldshop-karigor-tracker.vercel.app
Backend: https://goldshop-karigor-tracker.onrender.com

## Features
- JWT Authentication with Admin/Manager roles
- Invite-based Manager Registration
- Complete Karigor Work Item CRUD
- Auto color coding (Green/Yellow/Red)
- Daily 10AM email alerts for overdue items
- Export completed records to Excel
- Forgot Password with OTP
- Search, Filter, Sort, Pagination
- IST Timestamps

## Tech Stack
Node.js, Express, MongoDB, React,
Tailwind CSS, JWT, Nodemailer, ExcelJS
